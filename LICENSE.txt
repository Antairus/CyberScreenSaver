1. WHAT THIS SOFTWARE DOES - AND WHAT IT CHANGES
------------------------------------------------
CyberScreenSaver is a Windows screensaver. It draws animated effects on
each monitor, and the effect shown on each monitor is chosen in its
Settings window.

THE INSTALLER (it asks for administrator rights) CHANGES THIS COMPUTER:
  - It copies the screensaver into C:\Windows\System32 as
    CyberScreenSaver.scr, replacing an earlier copy. Every effect is
    inside that one entry. It removes CyberOscilloscope.scr,
    CyberClock.scr, CyberLiveNetwork.scr and CyberNetwork.scr when
    they are separate entries added by an earlier version of this
    Software. If Windows was set to one of them, choose
    CyberScreenSaver again in Screen Saver Settings.
  - It copies the program, this license, the README and the manual to
    %ProgramFiles%\KWTechSolutions\CyberScreenSaver.
  - It adds an entry to Windows' list of installed apps, so the
    Software can be removed from Settings > Apps.
  - It creates %ProgramData%\KWTechSolutions\CyberScreenSaver for its
    logs. Before it replaces or removes a file it copies the earlier
    one to that folder's "previous" subfolder, and it stops without
    changing anything if it cannot.
  - It does not change which screensaver Windows uses. You choose that
    yourself in Screen Saver Settings.
Removing the Software from Settings > Apps deletes the files, the
copies in "previous" and the entry listed above. It leaves the log
files, and each user's effect choices and downloaded data, in place.

WHILE IT RUNS, THE SCREENSAVER:
  - Saves each user's per-monitor effect choices under
    HKEY_CURRENT_USER\Software\CyberScreenSaver.
  - Writes a log automatically. Each run appends what it started, what
    it read or downloaded, and any error, as it happens, to a daily
    file in %ProgramData%\KWTechSolutions\CyberScreenSaver\logs. The
    file remains on that computer; nothing is transmitted anywhere.

SOME EFFECTS READ FROM YOUR NETWORK, THE INTERNET, OR THIS COMPUTER,
AND ONLY WHEN YOU CHOOSE THEM FOR A MONITOR. Live network, Radar and
War map use the network only while the screensaver runs full screen,
never in the small Settings preview:
  - LIVE NETWORK and RADAR SCAN YOUR LOCAL NETWORK. Every 30 seconds
    they read this computer's ARP table and send a ping (ICMP echo)
    request to addresses on this computer's local /24 subnet: those
    ending .1 to .30, eleven further fixed addresses (.100, .110, .150,
    .200, .247, .248 and .250 to .254), the default gateway, and every
    device already in the ARP table. For each device that answers they
    look up its name with a reverse DNS query and, when that finds
    none, a NetBIOS name query sent to the device. Scanning a network
    you are not authorized to manage may break that network's rules or
    the law. Choose these effects only on networks you are authorized
    to scan.
  - WAR MAP DOWNLOADS PUBLIC DATA FROM THE INTERNET. It downloads event
    files published by The GDELT Project from data.gdeltproject.org
    over plain HTTP: up to the last 24 hours of files (about 3 to 4 MB)
    when it starts, then one new file every 15 minutes. The files are
    kept for 25 hours in %LOCALAPPDATA%\KWTechSolutions\CyberScreenSaver\
    gdelt. Like any web request, a download reveals this computer's
    public IP address to that server. The events are read from news
    reports by a computer and are not verified; the map can show
    places, names and descriptions of fighting, assaults and protests.
  - SYSTEM MONITOR READS THIS COMPUTER whenever it is shown, including
    the Settings preview: processor, memory, graphics,
    disk and network activity, the names of running programs, drive
    sizes, and the computer's name, and shows them on screen. It sends
    nothing anywhere.
  - AI CORE READS THIS COMPUTER whenever it is shown, including the
    Settings preview. It runs the same reader as System monitor, so
    the same items listed above are read, and it shows only the
    processor load, in total and per processor, colouring its display
    by it. It sends nothing anywhere.
  - DAY/NIGHT CLOCK reads only this computer's clock and Windows'
    time-zone rules.

EVERYTHING THE OTHER EFFECTS SHOW IS MADE UP FOR DISPLAY. The
Intrusion terminal, Security console, Threat map and Data net show
invented intrusions, doors, badges, alarms, attacks and network
traffic. They do not detect, monitor, block, record or report
anything real, and they are not a security product.
